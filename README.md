# MeetPresenter - 谷歌会议音画同步展示与静默录屏平台

专为 **Google Meet（谷歌会议）**、Zoom、腾讯会议等远程视频会议设计的全能演示与高清录屏工作台。
通过浏览器单页面同时承载 **PDF/图片视觉浏览与批注**、**多批次后台音频播放** 以及 **静默多路混音录屏系统**，实现课件讲解、音频伴奏、远程参会者互动发言与主讲人麦克风的全方位视音频一体化录制与展示。

---

## 🌟 核心特性总览

### 0. 单文件便携绿色版 (`谷歌会议专用分享.html`)
- **纯原生前端单文件**：所有 CSS 样式、JavaScript 逻辑、音频混音节点完整内嵌于单一 `.html` 文件中；
- **随拷随走，零依赖**：无需安装 Node.js、Python 或后端环境，直接双击或拖入 Chrome / Edge 浏览器即可立享全套功能。

---

### 1. 静默高清录屏与多路混音系统 (NEW!)
无需安装任何三方录屏软件，页面深度集成 WebRTC 与 Web Audio API 硬件级录制内核：

- **极简静默边框指示（零杂物录入）**：
  - **录制进行中**：屏幕最四周边缘亮起 **科技蓝 4px 虚线框**；
  - **暂停状态**：虚线框静默变为 **琥珀黄 4px 虚线框**；
  - **结束录制**：虚线框自动隐去；
  - **绝无污染**：录制过程中没有任何红点、秒表、倒计时或文字气泡遮挡屏幕，全事件穿透，录出的视频 100% 纯净展示演示内容。
- **3 路声音无漏收录（硬件级混音台）**：
  - **桌面全局音频**：完美收录 Google Meet 参会者发言、系统提示音及本页面播放的背景音频；
  - **主讲人麦克风**：自动捕获主讲人话筒，并开启底层回声消除与硬件级自动增益补偿（AGC）；
  - **独立 GainNode 增益放大与动态压限**：
    - 麦克风通道单独配备 **250% 增益放大 (+8dB)**，解决麦克风人声容易被桌面背景音淹没的痛点；
    - 配备 **DynamicsCompressor 压限器**：小声说话自动提亮，大声演讲激昂时平滑防爆音，音质厚实饱满。
- **自定义快捷键盲操**：
  - 默认 **`F5`**：开始 / 停止录制（底层已屏蔽浏览器默认刷新行为）；
  - 默认 **`F7`**：暂停 / 继续录制（底层已屏蔽 Chrome 光标浏览行为）；
  - 支持在设置面板中点击后按下键盘任意键自定义绑定，自动持久化存储。
- **时间命名与零弹窗静默落盘**：
  - 停止录制时，视频自动以当前精确时间命名（如 `录屏_2026-10-30_23-11-00.mp4`）；
  - 支持在设置中绑定本地默认存储目录（File System Access API），录完直接静默写入文件夹；未指定时自动通过浏览器默认下载保存。
- **轻量高清体积**：
  - 采用 **H.264 视频 (1366x768 约 30fps) + AAC 48kHz 立体声** 编码；
  - 实测录制码率约 **2.1 Mbps**，录制 **1 个小时体积仅约 900 MB**（不足 1 GB），画质细腻清晰且极其节省硬盘空间。

### 2. 悬浮音频播放器（双形态与智能折叠）
- **完整操控形态**：包含播放/暂停、上一曲、下一曲、快退 5 秒、快进 5 秒、进度拖拽、音量与静音控制。
- **连播开关**：
  - **未勾选（默认）**：单曲播完自动停止并重置进度条；
  - **勾选“连播”**：播完自动顺播下一首，适合会议背景音乐轮播。
- **圆形呼吸图标形态**：鼠标离开播放器表面 **5 秒** 后自动平滑收缩为精致的圆形浮标（带唱片光圈与脉动）；鼠标悬停立即展开。
- **任意位置拖拽**：展开或折叠状态均支持鼠标按住自由拖拽到屏幕任意角落。
- **专属快捷键**：
  - <kbd>F1</kbd>：快退 5 秒
  - <kbd>F2</kbd>：播放 / 暂停
  - <kbd>F3</kbd>：快进 5 秒
  - <kbd>F4</kbd>：下一曲

### 3. PDF / 图片展示与阅读器交互
- **智能窗口宽度自适应**：导入或翻页时自动等比填充至浏览窗口最佳宽度，彻底告别水平滚动条。
- **平滑阅读控制**：
  - 鼠标滚轮自然上下滚动；
  - <kbd>←</kbd> / <kbd>→</kbd>：上一页 / 下一页；
  - <kbd>↑</kbd> / <kbd>↓</kbd>：平滑上下滚动视口；
  - 顶部导航栏支持自由缩放、放大、缩小与 100% 视图还原。

---

### 4. Canvas 涂鸦标注套件 (基于 Fabric.js)
- **画笔模式**：支持调色板自由选择颜色进行线稿重点圈画；
- **荧光笔模式**：半透明高亮，不遮挡文字背景；
- **文字标注模式**：鼠标点击页面任意位置打字添加备注；
- **橡皮擦模式**：点击批注对象快速局部擦除；
- **跨页状态记忆**：所有翻页批注自动留存，再次翻回原页时自动无缝复原。

---

### 5. 系统设置中心、随动丝带文字与走马灯
- **设置整合中心（齿轮 ⚙️）**：集中管理录屏快捷键、麦克风增强滑块 (100%~500%)、默认保存目录、标语文字与媒体导入。
- **鼠标随动幻彩丝带与环形自转文字**：
  - 移动鼠标时光标呈现 S 型蛇形丝带摆动；
  - 鼠标停顿时文字平滑收拢成 ⚪ 型圆环顺时针自转；
  - 全事件穿透，切换至橡皮擦或批注工具时智能避让。
- **窗口边缘四屏接力走马灯**：四条边框宛如独立屏幕依次接力传递展示自定义咨询标语。

---

### 6. 批次管理与侧边媒体抽屉
- **智能批次归集**：支持多文件或文件夹拖拽导入，自动分类图片、PDF 与音频并按自然文件名排序；
- **手动拖拽调序**：条目支持鼠标上下拖动自定义播放与展示顺序；
- **批次重命名与一键卸载**：可直接重命名批次，或一键卸载整批音画资源。

## 🖥️ 双屏幕会议与高清录制最佳操作流程

如果你拥有两个屏幕（笔记本主屏 + 外接扩展屏），这是目前体验最佳的“专业会议工作流”：

```
┌─────────────────────────────────┐       ┌─────────────────────────────────┐
│     屏幕 A (会议控制与个人操作)   │       │      屏幕 B (全屏专用展示台)     │
│                                 │       │                                 │
│  - 放置 Google Meet / 微信 / 笔记│       │  - 打开《谷歌会议专用分享.html》 │
│  - 查阅提纲、查看参会人员状态   │       │  - 按 F11 全屏展示 (PDF/音频/批注)│
│  - 绝不会被录入录像中           │       │  - 屏幕四周亮起蓝色虚线框静默录制 │
└─────────────────────────────────┘       └─────────────────────────────────┘
```

1. **就位全屏**：将浏览器窗口拖动到 **屏幕 B（演示屏）**，按下键盘 <kbd>F11</kbd> 全屏。
2. **开启录制 (<kbd>F5</kbd>)**：
   - 浏览器弹出捕获授权窗口，点击 **“整个屏幕 (Entire Screen)”**；
   - 选中 **屏幕 B**；
   - ⚠️ **重要**：务必勾选左下角的 **【同时共享系统音频 (Also share system audio)】**；
   - 点击“分享”，屏幕 B 四周出现 **蓝色虚线边框**，录屏与 3 路混音正式启动！
3. **沉浸式演讲讲解**：
   - 使用 <kbd>←</kbd> <kbd>→</kbd> 翻页，使用画笔划重点，随时按 <kbd>F2</kbd> 播放音频伴奏；
   - 突发私聊或喝水时，按 <kbd>F7</kbd> 边框变黄（暂停），讲完再按 <kbd>F7</kbd> 变蓝（继续）；
4. **结束录制 (<kbd>F5</kbd>)**：
   - 按下 <kbd>F5</kbd>，虚线框自动消失，录制的 MP4 视频文件已静默自动保存至设定文件夹中！

## 🛠️ 配套工具：`拖拽视频一键处理_FFmpeg.bat`

> 💡 **提示**：日常使用时，页面停止录制后直接输出标准 `.mp4` 文件，**完全不需要执行任何批处理转换**。该工具仅为可选的后期备用工具箱。

当遇到以下特殊情况时，将录像文件直接拖拽到 `拖拽视频一键处理_FFmpeg.bat` 图标上即可：
* **模式 [1] 极速标准 MP4 封装**：针对极少数旧版浏览器录出的 `.webm` 格式，1 秒无损流复制转为 MP4。
* **模式 [2] 智能增强人声与响度均衡**：调用 FFmpeg 的 `speechnorm` 动态算法，对录制时因坐得较远而偏小的麦克风人声进行后期提亮补偿，使人声与背景声达到完美平衡。

- **推荐浏览器**：Google Chrome 94+ 或 Microsoft Edge 94+（原生支持 WebRTC 双路内录与 H.264 MP4 硬件编码）；
- **系统要求**：Windows 10 / Windows 11；
- **数据隐私**：所有多媒体文件、标注与录像均在本地浏览器内存与磁盘中运行，绝不上云，保障会议文档的绝对安全。
