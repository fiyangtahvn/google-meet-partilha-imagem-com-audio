# MeetPresenter - 谷歌会议音画同步展示平台

专为 **Google Meet（谷歌会议）** 等远程会议标签页分享设计的媒体展示工作台。通过浏览器单标签页同时承载 **PDF/图片视觉浏览与批注** 与 **后台背景音频播放**，在开启 Google Meet 屏幕共享中的“同时分享标签页音频（Share tab audio）”时，参会人员能够实时、高清听到您播放的音频与讲解画面。

---

## 🌟 核心特性

0. **单文件便携绿色版 (`谷歌会议专用分享.html`)**
   - 已将所有 CSS 样式与 JavaScript 业务逻辑完整内嵌为一个独立的 `.html` 单文件；
   - 随拷随走，无需配置 Node.js 或后端环境，直接双击或拖入 Chrome/Edge 浏览器即可立享全套功能。

1. **批次管理与智能一二级目录树**
   - **导入即成批次**：无论是手动多选拖拽（如 10 张图 + 4 首音频）、拖入单个文件夹，还是同时拖入多个文件夹，系统均将其归集为一个明确的 **导入批次序列**（如 `批次 1 · 演示课件`）。
   - **一二级层级折叠树**：侧边媒体库提供树形目录浏览，一级为批次卡片（包含导入时间、文件数量总览），展开二级即可清晰查看属于该批次的“图片与文档”及“音频列表”。
   - **单文件独立卸载**：已导入列表中的每个文件条目后方均配备专属 **卸载图标**，随时单个移除。
   - **一键全部卸载本批次**：在批次头部提供批量卸载按钮，并在画面右键菜单中同步提供 **“全部卸载本批次内容”**，一键清除属于该批次的所有音画资源。

2. **悬浮音频播放器（双形态与智能折叠）**
   - **展开完整形态**：包含播放/暂停、上一曲、下一曲、快退 5 秒、快进 5 秒、进度拖拽、音量与静音控制。
   - **连播开关（复选框）**：底部音量拉杆右侧配备“连播”复选框：
     - **未勾选（默认）**：单曲播放完毕后自动停止，重置进度条并恢复停止状态；
     - **勾选“连播”**：当前音频播完后自动顺序播放下一首，保持连续播放；
     - 自动记忆并持久化您的勾选偏好。
   - **圆形图标形态**：当鼠标离开播放器表面后，将在 **5 秒** 后自动平滑收缩为精致的圆形浮标（带脉动与唱片光圈）；再次将鼠标移入表面即可立即唤醒并保持展开。
   - **双形态自由拖动**：无论处于展开状态还是折叠为圆形图标，均可随时按住拖动到屏幕任意位置。
   - **播放/暂停精准切换**：点击播放立即显示暂停图标，点击暂停立即切换为播放图标（快捷键同样同步切换）。
   - **专属快捷键深度绑定**：
     - <kbd>F1</kbd>：快退 5 秒（已拦截浏览器默认帮助弹窗）
     - <kbd>F2</kbd>：播放 / 暂停
     - <kbd>F3</kbd>：快进 5 秒
     - <kbd>F4</kbd>：下一曲

3. **PDF / 图片展示与阅读器交互**
   - **智能自动适应窗口宽度**：导入或翻页时自动计算并等比填充到当前浏览窗口最佳宽度，无水平滚动条困扰，极大提升 Google Meet 标签页共享时的观看体验。
   - **响应式自适应**：拖拽调整浏览器窗口大小或进入全屏时，页面内容自动保持宽度自适应。
   - **鼠标滚轮**：自然上下平滑滚动页面。
   - **键盘方向键**：
     - <kbd>←</kbd> / <kbd>→</kbd>：上一页 / 下一页（或切换上一个/下一个视觉文件）
     - <kbd>↑</kbd> / <kbd>↓</kbd>：等同于鼠标滚轮上下滚动视口
   - 支持放大、缩小、一键重新适应窗口宽度。

4. **Canvas 涂鸦标注套件 (基于 Fabric.js)**
   - 画笔标注模式（自选颜色）。
   - 荧光笔模式（半透明高亮）。
   - 文字标注模式（点击任意位置打字输入）。
   - 橡皮擦模式（点击对象快速擦除）。
   - 支持跨页面标注自动保存与恢复。

5. **全功能自定义右键上下文菜单**
   - 在主画面任意位置点击鼠标右键呼出：
     - 切换画笔 / 荧光笔 / 文字 / 橡皮擦 / 清空标注。
     - **选择其他已加载内容**：快速弹出媒体卡片矩阵进行切换。
     - **保存带标注的画面**：一键导出包含批注的高清图片。
     - **卸载当前已加载内容**：移除当前文档并平滑切换到下一份或回到导入区。
     - **全部卸载本批次内容**：智能识别当前展示文档所属的批次序列，一键彻底卸载整批全部图片、PDF 与音频。

## 🚀 如何在 Google Meet 中使用

1. 打开 Chrome 或 Edge 浏览器，直接双击或拖拽 `index.html` 打开本页面（无需额外搭建复杂后端服务器）。
2. 在本页面拖入包含课件、图片和配乐的文件夹。
3. 打开 Google Meet 会议室，点击底部的 **“立即共享屏幕 (Present now)”**。
4. 选择 **“Chrome 标签页 (A Tab)”**，选择当前打开的 **MeetPresenter** 标签页。
5. **重要**：确保勾选弹窗左下角的 **“分享标签页音频 (Share tab audio)”**。
6. 现在即可在演讲过程中自由演示 PDF/图片并播放背景音频、快进快退，对方能清晰听到高品质音频！
